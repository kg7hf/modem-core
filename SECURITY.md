# Security policy

This repository is teaching code: the transmit side of a MIL-STD-188-110A/B
serial-tone HF modem. It runs no service and handles no secrets, but if you find a
security problem in the code, or in how it is built and published, please report it
privately rather than in a public issue.

## Reporting

Use GitHub's private vulnerability reporting: the **Report a vulnerability** button
on this repository's **Security** tab. I will acknowledge the report as soon as I
can and keep you posted on the fix.

## What is supported

The latest commit on `main`. The tag for each article (for example `part-2`) is a
snapshot that matches its article and is not patched; fixes land on `main`.
